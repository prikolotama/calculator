# Отдельный калькулятор для GitHub Pages

## Что изменено

- Удалена подпись разработчика внизу страницы.
- Удален блок консультации в обоих режимах. Контакты в отчетах сохранены.
- Под кнопками сохранения и загрузки добавлена кнопка «Как это работает» с пояснением обмена файлами.
- Панель результата отображается полностью, без отдельной прокрутки.
- Внутри iframe калькулятор сообщает родительской странице высоту содержимого.

Методики, формулы, вопросы, формат сохранения и генерация отчетов сохранены.

## Публикация

1. Создайте отдельный репозиторий GitHub.
2. Загрузите содержимое этой папки в корень ветки `main`, включая `index.html`, `assets/`, `.nojekyll`, исходники и `package-lock.json`. Не загружайте `node_modules/`, `dist/`, `test-results/`.
3. В Settings → Pages выберите Deploy from a branch, ветку `main`, папку `/ (root)`.
4. После публикации откройте выданный GitHub адрес. Проверьте оба режима, сохранение и загрузку файла.
5. Передайте новый адрес для подготовки блока Т123. Старый код Т123 пока ссылается на исходный калькулятор.

Для следующих изменений (Node.js 22):

```sh
npm ci
npm run check
npm run test:e2e
npm run build:pages
```

После `build:pages` публикуйте обновленные `index.html` и `assets/` вместе с исходниками. Обычная команда `build` создает только `dist/`.

## Контракт будущего встраивания

Калькулятор внутри iframe отправляет сообщение `postMessage`:

```json
{ "type": "checku:resize", "version": 1, "height": 1234 }
```

Высота измеряется заново при изменении содержимого, ширины и загрузке шрифтов. Размер может как увеличиваться, так и уменьшаться. Ответы, реквизиты и результаты расчета не передаются. Сообщение отправляется с `targetOrigin: '*'`, поскольку адрес будущей страницы Тильды не зафиксирован; содержимое сообщения ограничено высотой.

Будущий код Т123 должен проверять `event.source`, `event.origin` нового сайта и числовую высоту. Сам по себе этот протокол не меняет высоту существующего iframe: необходим обработчик на стороне Тильды.

После деплоя отдельно проверяем встраивание на компьютере и телефоне, позиционирование всплывающих окон и переходы к результатам. Код Т123 готовится на этом этапе под фактический адрес.
